# 마법학교 질문탐험대: 사라진 빛의 별

유아부터 초등학교 3학년 수준을 위한 **질문 → 탐구 → 성찰**형 방 탈출 웹게임입니다.

- 외부 API와 회원가입 없이 실행
- 모바일·태블릿·PC 반응형
- 진행 상황을 브라우저 `localStorage`에 자동 저장
- 질문 선택에 따라 각 방에서 얻는 단서와 최종 답이 달라짐
- 캐릭터를 직접 움직여 방을 탐험하고 조사 지점에서 단서 획득
- 첨부 배경음악이 탐험 시작과 함께 재생되며 소리 버튼으로 켜기·끄기 가능
- 미션 완료 시 다음 방 포탈 생성
- 최종 답·근거·성찰을 함께 판정하여 굿엔딩 또는 재도전 엔딩 표시

## GitHub Pages 배포

1. 이 압축파일을 풉니다.
2. GitHub에서 새 저장소를 만듭니다.
3. 저장소의 **Add file → Upload files**를 누릅니다.
4. 압축을 푼 폴더 안의 모든 파일과 폴더를 업로드합니다.  
   `index.html`이 저장소의 가장 바깥에 있어야 합니다.
5. **Settings → Pages**로 이동합니다.
6. Source를 **Deploy from a branch**, Branch를 **main / (root)**로 선택하고 저장합니다.
7. 잠시 기다린 뒤 표시되는 GitHub Pages 주소로 접속합니다.

## 배경음악

- 첫 화면의 **탐험 시작** 또는 **이어서 탐험하기** 버튼을 누르면 재생됩니다.
- 모바일 브라우저의 자동 재생 제한을 고려해 사용자 버튼 입력 후 시작됩니다.
- 첫 재생이 보류된 모바일 기기에서는 다음 화면 터치 때 자동으로 재생을 다시 시도합니다.
- 다른 앱을 확인한 뒤 돌아오면 멈춘 위치에서 음악이 이어집니다.
- 오른쪽 위의 `🔊/🔇` 버튼으로 배경음악과 효과음을 함께 켜거나 끌 수 있습니다.
- 한 곡이 끝나면 자연스럽게 반복 재생됩니다.

## 게임 흐름

1. 잠든 초상화의 회랑: 최종 질문과 첫 생각 선택
2. 약초 온실: 캐릭터로 이동하며 질문과 관련된 관찰 단서 2개 찾기
3. 빗자루 우편실: 이동 경로와 순서를 보여 주는 핵심 단서 2개 찾기
4. 음악 계단: 빛과 소리의 규칙을 보여 주는 핵심 단서 2개 찾기
5. 중앙탑: 답·근거·성찰 연결

## 탐험 조작

- 모바일·태블릿: 화면 왼쪽 아래 가상 방향키로 이동, 오른쪽 아래 **조사** 버튼 사용
- PC: 키보드 방향키 또는 `WASD`로 이동, `Space` 또는 `E`로 조사
- 좌우 이동은 옆모습, 아래 이동은 정면, 위 이동은 뒷모습 걷기 모션으로 전환됩니다.
- 빛나는 물체 가까이 가면 조사 버튼이 노란색으로 활성화됩니다.
- 조사 지점은 처음부터 표시되지 않으며 가까이 접근했을 때만 작은 별빛으로 반짝입니다.
- 같은 방에서도 선택한 질문에 따라 핵심 단서가 되는 물체와 단서 내용이 달라집니다.
